## 1. 概述与愿景

### 1.1 背景

这是一门移动互联系统的课设，选题自由度高。灵感来自《星露谷物语》，但目标不是做一款"移动版星露谷"，而是把《星露谷》里那种**"经营一块属于你的地方、自己决定怎么过"**的感觉，迁移到现实地理空间上。

《星露谷》的核心体验可以压缩成一句：你拿到一块荒地，投入时间与体力，把它变成属于自己的家。本项目的对应体验是：你走进一座真实的校园，投入真实的脚步与注意力，把它变成属于自己的世界。

### 1.2 一句话定位

> 一款基于现实地理空间的生活模拟探索 RPG：玩家通过真实行走解锁地图迷雾，把经过的地点、天气、人物与事件记录成"我的世界"，并在表层生活之下逐步触达传闻、异常与历史第二张地图。

### 1.3 核心卖点

> 每个人，都生活在属于自己的开放世界里。

### 1.4 与《星露谷》的继承与放弃

**继承**

- 开放式玩法：不强制单一目标，玩家可自由选择"农场主 / 钓鱼佬 / 矿工 / 社交达人 / 装修狂"式的个人路线。
- "每天做点什么"的节奏感：用有限的时间与体力做资源分配。
- 生产与建设：采集、种植、钓鱼、加工成更高价值的产物。
- 收集图鉴：把零散玩法串起来的主线（社区中心 → 世界图鉴）。
- NPC 关系：好感度驱动的剧情解锁。
- 季节与节日：周期性刷新世界状态。

**放弃 / 改造**

| 星露谷 | 本项目 |
| --- | --- |
| 体力条 | 现实中真实的时间与体力 |
| 金币 | 记忆、知识、探索量与"痕迹" |
| 虚拟农场 | 真实的校园地图 |
| 战斗与怪物 | 异常、传闻与调查 |
| 主线任务 | 世界图鉴 + 传闻解锁的结构性引导 |
| 虚拟种植在田地里 | 种植在"我的空间"里的种植台，由天气与步数驱动 |

## 2. 核心概念与已拍板决策

以下三个决策已在讨论中确定，是全部后续设计的前提：

1. **主灵魂 = 生活记忆 与 神秘异常 对半**，用"双层世界"统一，而不是做成两个平行 App。
2. **地图基底 = 真实坐标 + 虚拟叠加层**：以真实校园地理为骨架，在其上叠加虚拟的异常、传闻、历史第二张地图。
3. **第一版范围 = 单一校园**：把一所大学当作完整的"小型开放世界"。

### 2.1 双层世界机制

游戏世界分为两层，而不是把记忆和异常并列成两条线：

- **表层（生活 / 记忆）**：白天、真实天气、真实地点、NPC 作息、生产建设、日记图鉴。玩家大多数时间在此层。
- **深层（异常 / 神秘）**：只在特定时空条件下"翻面"——深夜、下雨、特定日期，叠加在特定地点上。此层出现传闻证实、历史第二张地图、异常事件。
- **记忆是钥匙**：玩家的探索度、图鉴完成度、NPC 熟悉度越高，越能看到表层之下的异常。一个人若从不记录，就永远只看到普通校园。

这一机制把"记忆"和"异常"变成一条因果链：先好好生活，才能看见生活底下藏着什么。它也直接产出一句叙事钩子。

### 2.2 探索四层结构

任何一次探索都沿着四层递进，这是内容设计的总骨架：

1. **现实**：我走到了一个地方。
2. **发现**：我发现了这个地方。
3. **故事**：我发现了这个地方背后的历史与人物。
4. **传说**：我发现了一个不知道是否真实的东西。

## 3. 核心游戏循环

### 3.1 主循环

```text
现实生活
   ↓
去某个地方（真实行走）
   ↓
发现新的东西（地点 / 资源 / 人物 / 事件）
   ↓
获得「知识 / 物品 / 记忆」
   ↓
解锁新的线索
   ↓
去探索新的地方
   ↓
形成自己的故事
   ↓
写入「我的世界」
   ↓
继续生活
```

### 3.2 与传统 RPG 的区别

传统 RPG 循环是`接任务 → 打怪 → 得经验 → 升级`，数值驱动。本项目循环是`生活 → 探索 → 发现 → 记录 → 解锁 → 再探索`，由玩家真实的脚步与选择驱动。

### 3.3 玩家的"一天"

玩家的一天没有强制日程，大体是：出门前看一眼**今日世界播报**，决定今天去哪、做什么（采集、钓鱼、拜访 NPC、追一条传闻、纯散步记账）。一天的收益沉淀为地图探索度、图鉴条目、记忆节点与关系进展，而不是一串金币。

## 4. 设计原则

1. **记录生活，而不是命令生活**。不设计"每件事 +XP"。游戏负责把经历沉淀下来，不强迫玩家为了数字做事。
2. **世界是活的**。同一地点在不同时间、天气、季节就是不同的地点；天气与时间要真正改变可玩内容，而非仅是一行 UI。
3. **密度优先于规模**。先做透一个校园，不铺大。
4. **真正的成本是时间与探索量**。稀缺资源是玩家的注意力与脚步，不是金币。
5. **系统之间互相咬合**。孤立地玩任何一个系统都会有缺口，需要别的系统来补，从而自然把玩家引向全局（对应星露谷社区中心的"缺什么补什么"）。

## 5. 世界观与设定

### 5.1 地图 = 一所大学

一所校园天然具备构成一个小型开放世界的所有要素：建筑、道路、NPC（师生/后勤/摊贩）、社团、商店、宿舍、食堂、隐藏角落、真实的历史与传闻。第一版全部内容都落在这一所学校内，玩家以真实定位在其中移动。

### 5.2 时间维度

世界不仅有空间维度，还有时间维度。玩家收集足够的历史资料后，可解锁**历史第二张地图**，看到同一地点的过去样貌（例如 20 年前、40 年前），现实中已消失或改建的建筑会出现在历史层。

### 5.3 历史与档案

校园的真实历史（老照片、建成年份、曾用名、变迁事件）与虚构传闻混合，构成深层内容的主体素材。历史层是"真实史实 + 虚构补充"的组合，需在内容设计时明确标记哪些是实、哪些是虚，避免误导。

## 7. 核心系统

### 7.1 地理与迷雾（世界认知系统）

玩家初次进入，地图大部被迷雾覆盖。迷雾不是简单的地图解锁，而是"对世界的认知"。玩家真实行走后，道路、地点、历史、NPC、事件、传闻、他人足迹随之显现。

- 迷雾的判定基于真实定位，进入某区域半径后才解除。
- 迷雾解锁的不是"一整块土地"，而是一层层信息：先显现地点，再显现历史，再显现传闻，再显现异常线索。
- 地图规模受限但不限死：第一版聚焦单一校园，未来可扩展周边街区、整座城市。

### 7.2 地点系统

地图上的每个可识别地点是一等公民，拥有独立档案：

- 名称、坐标、类型（建筑 / 自然 / 公共 / 隐藏）。
- 建成/改建年份、曾用名、一段可解锁的历史。
- 关联的资源点、NPC、事件、传闻。
- 玩家的首次发现时间与个人记忆节点。

发现一个地点即触发"[发现]"记录，并写入地点图鉴。

### 7.3 时间 / 天气 / 季节 / 世界状态

这些因素直接改变可玩内容，而非仅展示：

- **天气**（晴 / 阴 / 雨）：雨天限制部分 NPC 出现，产生积水点，触发特定资源（雨后蘑菇）、事件与传闻。
- **昼夜**：夜晚地图"变脸"——空荡的校园、仅在夜间出现的地点 / NPC / 传闻 / 异常。
- **季节**：春季樱花、秋季银杏等季节点只在对应季节可采集；作物与鱼种随季节轮换。
- 世界状态由"当前时间 + 天气 + 季节 + 玩家进度"共同决定，是"活世界"的引擎。

### 7.4 探索与足迹

系统记录玩家走过的路线与其特征，但不定位成运动 App：

- 足迹呈现探索覆盖度、本周步数、新发现地点数。
- 重点落点是"我在这个世界留下的痕迹"，以及与"历史层""他人足迹"的对照。
- 足迹可连点成线，形成"路线"（如"走过一整条银杏道"）触发轻量成就。

### 7.5 采集（亲临资源点）

真实校园里的自然与人文载体是资源点，玩家必须亲临才能采集，从而保住"走路=探索"的核心：

- **自然点**：湖/河、花坛、草坪、老树、树林。
- **人文点**：老建筑、石碑、雕塑、涂鸦墙、牌匾。
- **季节点**：樱花只在春天、银杏只在秋天。

采集物归入六类资源（见 7.12），种类随季节、天气、昼夜变化。大部分采集物"先别卖"，因为后续图鉴、加工、NPC、传闻解锁都会用到（对应星露谷"留一些奇怪的东西"的教训）。

### 7.6 种植（我的空间 · 种植台）

不要求玩家去真实泥地开垦。玩家在"我的空间"里放置种植台，把探索获得的种子种下：

- 生长进度 = 真实时间 + 真实天气 + 玩家今日探索量。
- 示例：下雨且当日步数较高，作物进度额外增长，形成"走路=浇水"的隐喻。
- 作物成熟后进入加工链或图鉴捐赠。

### 7.7 钓鱼

校园内凡有水体处即为钓鱼点。保留《星露谷》"控制滑块让鱼保持在区域内"的轻量小游戏（可进一步简化）：

- 鱼种随季节、天气、昼夜变化，构成"鱼图鉴"的一类。
- 稀有鱼限定特定条件出现（如"下雨的傍晚"），天然接入传闻层。
- 钓鱼产出进入加工链。

### 7.8 加工与生产链

对应星露谷"作物 → 加工品 → 更高价值"：

- 采集物 / 作物 / 鱼 → 加工台 → 纪念品、料理、地图道具等。
- 坚定克制一条：产物不是用来换金币，而是进入三类用途（送 NPC 提升关系、捐图鉴 / 挂墙沉淀记忆、作为解锁传闻或异常的钥匙）。
- 货币采用"时间 + 探索量"本身，最多加一个很轻的"纪念币/声望"，不做经济模拟器。

### 7.9 建设（宿舍 = 我的空间）

玩家拥有一个"我的空间"（对应校园语境为宿舍），可扩建、摆家具、挂照片与图鉴：

- 空间是"现实冒险博物馆"，不是单纯仓库。
- 建设与玩法挂钩，而非纯装饰：升级加工台才能加工、升级地图桌才能查看历史第二张地图。

### 7.10 日记与记忆节点

项目定位中的"灵魂系统"：

- 玩家可在任一时间地点记录文字与照片，系统生成带坐标、时间戳的记忆节点。
- 这些节点落在地图上，未来走过时触发"你曾经来过这里"的呼应。
- 记忆节点既是个人收藏，也是进入深层（异常解锁）的进度依据。

### 7.11 世界图鉴

类似星露谷的收集系统，但收集的是"对世界的认知"，是整个游戏的结构性主线：

- **地点图鉴**、**自然图鉴**（植物/动物/天气）、**人物图鉴**（NPC）、**历史图鉴**（事件/建筑/老照片）、**传闻图鉴**（都市传说/未确认事件）、**知识图鉴**（学到的信息）、**记忆图鉴**（自己的生活）。
- 图鉴完成度反向决定深层可见度（"记忆是钥匙"）。

### 7.12 资源与货币

资源分为六类，这是项目区别于传统 RPG 的核心点：

1. **物质 Material**：食物、植物、矿物、手工物、地图碎片、收藏品。
2. **知识 Knowledge**：地点与历史的信息（"这栋楼建于 1987 年"）。
3. **记忆 Memory**：玩家的个人经历与记忆节点。
4. **文化 Culture**：当地传说、老建筑、历史人物、地方食物、节庆、民俗。
5. **足迹 Trace**：自己走过的路线（探索覆盖）。
6. **故事 Story**：地点 + 人 + 时间 + 历史 + 玩家行为组合而成的高级产物。

货币层面：以"探索量"为核心尺度，辅以极轻量的纪念币/声望，明确拒绝金币驱动的经济模拟器。交易若有，优先设计成**信息经济**（交换线索、发布发现换声望），而非现实物价。

### 7.13 NPC 与熟悉度

NPC 定位为"世界的记忆载体"，其价值在于通过关系推进揭示世界观，而非派发采集任务：

- 每个 NPC 有作息表（如 07:30 宿舍 → 08:00 教学楼 → 12:00 食堂），叠加少量随机变化，即产生生命感。
- 关系系统用**熟悉度 / 关系**命名，层级如"陌生人 → 见过几次 → 认识 → 熟悉 → 朋友 → 知己"，靠共同经历、帮助、对话、交换信息、分享记忆推进，而不是每天送礼刷满。
- NPC 对话随熟悉度逐层深入，最终指向世界观与历史线索（如"老操场以前是什么"）。
- 第一版可预设少量 NPC + 简单表现，AI / LLM 只作为后期增强，不作为前提。

### 7.14 随机事件

随机事件提供"今天不知道会发生什么"的探索欲，但不做纯 Roguelike：

- 事件分档：普通（下雨）、少见（彩虹）、稀有（角落遇见狐狸）、极稀有（流星雨）、神秘（某地点出现未知标记）。
- 事件应是引子，把玩家引向地点 / NPC / 传闻 / 异常，而不是一次性奖励。

### 7.15 传闻系统

地图上出现"传闻"标记，玩家获得一条未证实信息（如"晚上十点后旧体育馆附近有奇怪声音"）：

- 玩家据此在特定时间、地点蹲守，可能落空，也可能触发真实内容。
- 这是轻量的"现实都市传说 / ARG"玩法，也是深层内容的入口。

### 7.16 世界异常（深层）

深层内容的核心载体：

- 特定地点在特定时间（多为夜晚 / 雨天）进入"异常态"，地图出现异常标记。
- 异常不是战斗，而是**调查**：拍照、收集线索、找 NPC、拼接历史，最终"解决"异常。
- 解决异常可解锁历史第二张地图的碎片或深层传闻。

### 7.17 历史第二张地图（时间维度）

收集足够历史资料后，玩家可切换到历史地图，看到同一地点的过去：

- 例：2026 年的图书馆 ↔ 2006 年的老图书馆 ↔ 1986 年的已拆除宿舍。
- 历史图使地图拥有空间与时间两个维度，是本项目区分于普通地图打卡 App 的关键之一。

### 7.18 轻社交（非实时）

社交取向为非实时、低压力，强调"现实世界被很多人共同书写"：

- **漂流瓶**：在真实地点留下一条消息，后来者经过发现并可回复。
- **玩家足迹**：地图上浮现其他玩家的路线，制造"原来也有很多人走过这里"的感受。
- **共享记忆**：某地点可查看"过去 30 天有 N 人记录过这里"，并可浏览他人留下的影像。
- 第一版可用本地 / 模拟数据呈现，真实多人在线作为后期。

### 7.19 节日（校园真实节点）

把真实校园周期点做成星露谷式"节日"，注入时间轴仪式感：

- 开学、樱花季、银杏季、毕业季等作为周期性事件，触发限定资源、NPC 聚集、限定内容。

### 7.20 职业 / 生活方向

不做"战士 / 法师 / 猎人"式的职业，而让角色由玩家的真实行为塑造：

- 方向示例：自然探索者、历史学者、记录者、探险家、生活家、漫游者。
- 玩家经常探索历史 → 系统提示"历史研究能力提升"；经常拍照 → "记录能力提升"。
- 结论口号：你的角色由你的现实生活塑造。此系统优先级偏低，可延后。

### 7.21 今日世界播报（保持期钩子）

每天一句动态播报，如"旧礼堂今天在下雨""傍晚的湖面有传闻"，构成让玩家回来看一眼的日常理由，替代打卡签到式的强迫机制。

### 7.22 成长 / 探索度（替代等级）

不做 Lv / XP 数字，改以探索度与世界观呈现：

- 校园探索度、已发现地点 / 历史 / 人物 / 传闻 / 记忆的数量。
- "世界观"：随着探索，玩家对世界的认知越来越完整。

## 8. 玩家第一周体验（"第一年春"类比）

作为 demo 叙事与新手引导的参照，设计玩家前七天的目标弧线：

- **Day 0（新手引导）**：进入校园，解锁"我的空间"与种植台，发现第一个地点（旧礼堂），学会记录一条记忆节点。
- **Day 1–3（表层熟悉）**：采集、钓鱼、拜访一两位 NPC，图鉴出现第一批条目，探索度稳步上升。
- **Day 4–7（首次触达深层）**：因探索度 / 图鉴达到阈值，或依一条传闻在特定时间地点蹲守，第一次触发异常 / 历史第二张地图碎片，打开"生活之下"的认知入口。
- 此后进入自由循环，由玩家自选路线。

## 9. 范围与优先级

### P0（核心，一定做）

地理地图 + 迷雾、探索/足迹、地点系统、时间/天气/世界状态、日记 + 照片 + 记忆节点、世界图鉴、采集、种植、钓鱼、加工、建设（我的空间）、资源与货币（六类）。

### P1（第二层，非常值得做）

随机事件、NPC 与熟悉度、历史/档案、漂流瓶/玩家痕迹、传闻、知识/文化资源、世界异常、历史第二张地图、轻社交、节日。

### P2（有余力再做）

我的空间深化、关系系统、职业/生活方向、轻经济、遗迹/考古、世界异常深化、今日世界播报、成长/探索度可视化。

### 明确不做（第一版）

战斗、大量敌对生物、复杂装备系统、重度等级/XP、完整经济模拟器。这些不是不能做，而是会把项目带向另一个方向，与"现实探索"的核心定位冲突。
