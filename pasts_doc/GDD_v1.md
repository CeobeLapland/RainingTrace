## 1. 概述与愿景

### 1.1 背景

这是一门移动互联系统的课设，选题自由度高。灵感来自《星露谷物语》，但目标不是做一款"移动版星露谷"，而是把《星露谷》里那种"经营一块属于你的地方、自己决定怎么过"的感觉，迁移到现实地理空间上。

《星露谷》的核心体验可压缩为一句：你拿到一块荒地，投入时间与体力，把它变成属于自己的家。本项目对应：你走进一座真实的校园，投入真实的脚步与注意力，把它变成属于自己的世界。

### 1.2 一句话定位

> 一款基于现实地理空间的生活模拟探索 RPG：玩家通过真实行走解锁地图迷雾，把经过的地点、天气、人物与事件记录成"我的世界"，可以养成、生产建设、和虚拟人物动物互动，并在表层生活之下逐步触达传闻、异常与历史第二张地图。即：探索+记录+养成+互动。

### 1.3 核心卖点

> 每个人，都生活在属于自己的开放世界里。

### 1.4 与《星露谷》的继承与放弃

**继承**

- 开放式玩法：不强制单一目标，玩家自由选择"农场主 / 钓鱼佬 / 矿工 / 社交达人 / 装修狂"式的个人路线。
- "每天做点什么"的节奏感：用有限的时间与体力做资源分配。
- 生产与建设：采集、种植、钓鱼、加工成更高价值的产物。
- 收集图鉴：把零散玩法串起来的主线。
- NPC 关系：好感度驱动的剧情解锁。
- 季节与节日：周期性刷新世界状态。

**放弃 / 改造**

| 星露谷 | 本项目 |
| --- | --- |
| 体力条 | 现实中真实的时间与体力 |
| 金币 | 探索量、记忆、纪念币、声望 |
| 虚拟农场 | 真实的校园地图 |
| 战斗与怪物 | 异常、传闻与调查 |
| 主线任务 | 世界图鉴 + 传闻解锁的结构性引导 |
| 田间种植 | 我的空间里的种植台 / 养鱼池，由天气与步数驱动 |

## 2. 核心概念与已拍板决策

以下决策已确定，是后续设计的前提：

1. **主灵魂 = 生活记忆 与 神秘异常 对半**，用"双层世界"统一。
2. **地图基底 = 真实坐标 + 虚拟叠加层**：真实校园地理为骨，其上叠加虚拟异常、传闻、历史第二张地图。
3. **第一版范围 = 单一校园**（校内有湖，满足钓鱼前提）。
4. **玩家可配置优先**：单机/多人、定位精度与策略、NPC 是否接外部 API，均由玩家自行配置（贯穿全篇）。

### 2.1 双层世界机制

- **表层（生活 / 记忆）**：白天、真实天气、真实地点、NPC 作息、生产建设、日记图鉴。
- **深层（异常 / 神秘）**：在"深夜 / 下雨 / 特定日期 × 特定地点"翻面，出现传闻证实、历史第二张地图、异常事件。
- **记忆是钥匙**：探索度、图鉴完成度、NPC 熟悉度越高，越能看见表层之下的异常。

这一机制把"记忆"和"异常"变成一条因果链：先好好生活，才能看见生活底下藏着什么。

### 2.2 探索四层结构

1. **现实**：我走到了一个地方。
2. **发现**：我发现了这个地方。
3. **故事**：我发现了这个地方背后的历史与人物。
4. **传说**：我发现了一个不知道是否真实的东西。

## 3. 核心游戏循环

### 3.1 主循环

```text
现实生活
   ↓
去某个地方（真实行走）
   ↓
发现新的东西（地点 / 资源 / 人物 / 事件）
   ↓
获得「知识 / 物品 / 记忆」
   ↓
解锁新的线索
   ↓
去探索新的地方
   ↓
形成自己的故事
   ↓
写入「我的世界」
   ↓
继续生活
```

### 3.2 探索与养成的闭环

探索与养成不是两条线，而是一条焊死的环：

```text
探索采料 → 养成(建造/工具/图鉴/生灵) → 能力变强 → 更深探索
```

探索产出原料，养成把原料变成可见的成长（家变大、工具变强、图鉴变满），更强的能力反过来解锁更深的内容。这是《星露谷》核心闭环在现实地理上的移植。

### 3.3 与传统 RPG 的区别

传统 RPG 循环是`接任务 → 打怪 → 得经验 → 升级`，数值驱动。本项目循环是`生活 → 探索 → 发现 → 记录 → 解锁 → 再探索`，由玩家真实的脚步与选择驱动。

### 3.4 玩家的"一天"

出门前看一眼今日世界播报，决定今天去哪、做什么（采集、钓鱼、拜访 NPC、追一条传闻、纯散步记账）。一天的收益沉淀为地图探索度、图鉴条目、记忆节点与关系进展，而非一串金币。

## 4. 设计原则

1. **记录生活，而不是命令生活**。不设计"每件事 +XP"。
2. **世界是活的**。同一地点在不同时间、天气、季节就是不同的地点。
3. **密度优先于规模**。先做透一个校园。
4. **真正的成本是时间与探索量**。稀缺资源是玩家的注意力与脚步。
5. **系统之间互相咬合**。孤立玩任何一个系统都会有缺口，需要用别的系统来补。
6. **内容数据驱动**。地图、NPC、任务、资源、事件、养成全部是配置/数据，代码只是读取引擎。这是自定义模式与可扩展性的前提。
7. **养成不膨胀数值**。养成提供"不确定的收集乐趣 + 可见成长"，不靠金币与战斗膨胀。

## 5. 世界观与设定

### 5.1 地图 = 一所大学

一所校园天然具备构成小型开放世界的要素：建筑、道路、NPC、社团、商店、宿舍、食堂、隐藏角落、真实历史与传闻。第一版全部内容落在这所学校内，玩家以真实定位移动。

### 5.2 时间维度（两层）

- **现在地图**：玩家日常所在。
- **过去地图**：收集足够历史资料后解锁，展示同一地点的过去样貌（现实中已消失或改建的建筑出现于此）。

第一版只做两层，不展开多时代。

### 5.3 历史与档案

校园真实历史（老照片、建成年份、曾用名、变迁事件）与虚构传闻混合，构成深层内容素材。内容设计时明确标记哪些是史实、哪些是虚构，避免误导。

## 7. 核心系统

### 7.1 地理与迷雾（世界认知系统）

玩家初次进入，地图大部被迷雾覆盖。迷雾不是简单的地图解锁，而是"对世界的认知"，玩家真实行走后，道路、地点、历史、NPC、事件、传闻、他人足迹随之显现。

- 地图基底用开源免费瓦片（OpenStreetMap 方向）。
- 迷雾用六边形格子拼合，进入某格半径后解除。
- 迷雾分层显现：先地点，再历史，再传闻，再异常线索。
- 定位精度、定位时间、耗电策略做成玩家可配置项。

### 7.2 地点系统

每个可识别地点是一等公民，拥有独立档案：名称、坐标、类型、建成/改建年份、曾用名、一段可解锁历史、关联的资源点和事件、玩家首次发现时间与个人记忆节点。发现即触发"[发现]"并写入地点图鉴。

### 7.3 时间 / 天气 / 季节 / 世界状态

这些因素直接改变可玩内容：

- 天气：雨天限制部分 NPC 出现、产生积水点、触发特定资源（雨后蘑菇）与事件。
- 昼夜：夜晚地图"变脸"，仅夜间出现地点 / NPC / 传闻 / 异常。
- 季节：季节点只在对应季节可采集，作物与鱼种随季节轮换。
- 世界状态由"当前时间 + 天气 + 季节 + 玩家进度"共同决定。

### 7.4 探索与足迹

记录玩家走过的路线，不做运动 App 定位：

- 展示探索覆盖度、本周步数、新发现地点数。
- 落点是"我在这世界留下的痕迹"，并与历史层、他人足迹对照。
- 连点成线形成"路线"，触发轻量成就。

### 7.5 采集（亲临资源点）

真实校园的自然与人文载体是资源点，须亲临才能采集：

- 自然点：湖/河、花坛、草坪、老树、树林。
- 人文点：老建筑、石碑、雕塑、涂鸦墙、牌匾。
- 季节点：樱花只在春天、银杏只在秋天。

采集物归入六类资源，种类随季节、天气、昼夜变化。大部分"先别卖"，图鉴、加工、NPC、传闻解锁都会用到。

### 7.6 种植（我的空间 · 种植台）

玩家在"我的空间"放置种植台，把探索获得的种子种下：

- 生长进度 = 真实时间 + 真实天气 + 玩家今日探索量。
- 下雨且步数高时作物进度额外增长，形成"走路=浇水"隐喻。
- 成熟后进加工链或图鉴捐赠。

### 7.7 钓鱼与养鱼

校园有湖，作为钓鱼点存在。钓鱼小游戏延后，当前用"种鱼/养鱼"为主：

- 钓鱼获取鱼苗，返回"我的空间"放入鱼池继续养成、繁殖，可出稀有。
- 保留钓鱼为获取鱼苗的轻交互（非占主玩法）。
- 鱼图鉴作为记忆图鉴的一类，稀有鱼限定"下雨的傍晚"等条件出现，接入传闻层。

### 7.8 加工与简化产线

对应星露谷"作物 → 加工品 → 更高价值"，但产线只做简化版：

- 有限的机器种类，例：腌菜罐→纪念罐、蜂箱、复制机等。
- 玩家摆放机器，手动或定时进料出料，材料自动流转一次。
- 不做自动化路由、管线、复杂红石逻辑，避免滑向工业自动化游戏。

产物坚定克制：不进金币，而是进三类用途——送 NPC 提升关系、捐图鉴/挂墙沉淀记忆、作钥匙解锁传闻或异常。

### 7.9 建设与自由建造（我的空间）

玩家空间采用网格化自由摆放，具备 Minecraft 式建造自由度：

- 探索采集的木/石/砖作为建材，扩建房间、摆机器、铺物件。
- 空间是"现实冒险博物馆"，不是单纯仓库。
- 建设与玩法挂钩：升级加工台才能加工，升级地图桌才能查看过去地图。

### 7.10 工具升级线

把星露谷"锄头→铜→铁→金"映射成探索工具，用探索材料升级，反哺探索效率：

- 地图探测器：扩大迷雾解锁半径。
- 采集篮：扩容。
- 钓鱼竿：提升获取鱼苗效率。
- 相机：解锁更多记忆节点与图鉴能力。
- 夜行手电：延长夜间探索能力。

这是把探索与养成焊死的关键系统。

### 7.11 宠物 / 友善生灵

校园里发现的友善生灵（野猫、鸟、松鼠）可"领养"回"我的空间"，进行电子宠物式养成：

- 喂食、互动、培养感情。
- 稀有生灵构成收集目标。
- 补上动物养成这条缺口，完全不涉及战斗。
- 一个被领养的生灵同时是一个记忆节点。

### 7.12 稀有变异收集

作物、鱼、生灵在特定条件下触发"稀有变异"：

- 条件示例：雨夜浇水、特定季节、特定地点采集。
- 稀有产物进收集图鉴支线，制造"再来一次"的动力。

### 7.13 日记与记忆节点

项目定位中的"灵魂系统"：

- 任一时间地点记录文字与照片，生成带坐标、时间戳的记忆节点。
- 节点落在地图，未来走过时触发"你曾经来过这里"。
- 记忆节点既是个人收藏，也是进入深层的进度依据。

### 7.14 世界图鉴

收集的是"对世界的认知"，是结构性主线：

- 地点图鉴、自然图鉴、人物图鉴、历史图鉴、传闻图鉴、知识图鉴、记忆图鉴。
- 完成度反向决定深层可见度（记忆是钥匙）。

### 7.15 资源与货币

资源六类：

1. **物质 Material**：食物、植物、矿物、手工物、地图碎片、收藏品。
2. **知识 Knowledge**：地点与历史的信息。
3. **记忆 Memory**：个人经历与记忆节点。
4. **文化 Culture**：当地传说、老建筑、历史人物、地方食物、节庆。
5. **足迹 Trace**：自己走过的路线。
6. **故事 Story**：地点 + 人 + 时间 + 历史 + 行为组合而成的高级产物。

货币定为三币制，各管一摊，避免刷分：

- **探索量**：进度门槛、解锁钥匙。
- **纪念币**：兑换、装饰、自定义内容。
- **声望**：社交、购买线索。

交易层面优先做信息经济（交换线索、发布发现换声望），不做金币驱动的经济模拟器。

### 7.16 NPC 与熟悉度

NPC 是"世界的记忆载体"，价值在于揭示世界观，而非派发采集任务：

- 每个 NPC 有作息表，叠加少量随机变化。
- 关系层级：陌生人 → 见过几次 → 认识 → 熟悉 → 朋友 → 知己，靠共同经历、帮助、对话、交换信息、分享记忆推进。
- 双轨配置：默认使用预设对话（兜底，离网可玩）；玩家可选择接入自己的 API 定制 NPC 表现（仅作增强）。
- 需统一 NPC 配置 schema，保证两条轨共用同一数据结构。

### 7.17 随机事件

提供"今天不知道发生什么"的探索欲，不做纯 Roguelike：

- 分档：普通（下雨）、少见（彩虹）、稀有（角落遇见狐狸）、极稀有（流星雨）、神秘（某地点出现未知标记）。
- 事件作为引子，把玩家导向地点 / NPC / 传闻 / 异常。

### 7.18 传闻系统

地图出现"传闻"标记，玩家获得一条未证实信息，据此在特定时间地点蹲守，可能落空也可能触发真实内容。这是轻量"现实都市传说 / ARG"玩法，也是深层入口。扑空是合法结果。

### 7.19 世界异常（特殊任务）

深层内容核心载体，但并入统一任务池，作"特殊任务"标签，与 NPC 任务共用一套任务数据结构：

- 触发条件 = 时空条件 + 探索度门槛，而不是无限接取。
- 异常不是战斗，而是调查：拍照、收集线索、找 NPC、拼历史，最终解决。
- 解决异常可解锁过去地图碎片或深层传闻。
- 支撑机制同样覆盖 NPC 任务，避免为异常另起炉灶。

### 7.20 历史第二张地图（时间维度）

收集足够历史资料后，切换到"过去地图"，看到同一地点的过去样貌。第一版仅两层（现在 / 过去）。

### 7.21 轻社交（非实时，玩家可配置）

非实时、低压力，强调"现实世界被很多人共同书写"：

- 漂流瓶：在真实地点留消息，后来者发现并回复。
- 玩家足迹：地图浮现其他玩家路线。
- 共享记忆：某地点查看"过去 30 天有 N 人记录"并浏览他人影像。
- 玩家可配置：单人模式不显示他人内容；多人模式才显示漂流瓶、足迹、共享记忆。

### 7.22 节日（校园真实节点）

开学、樱花季、银杏季、毕业季作为周期性事件，触发限定资源、NPC 聚集、限定内容。由人工维护配置。

### 7.23 职业 / 生活方向

角色由玩家的真实行为塑造：

- 方向示例：自然探索者、历史学者、记录者、探险家、生活家、漫游者。
- 玩家行为取向自然提升对应能力（探索历史 → 历史研究能力提升）。
- 优先级偏低，可延后。

### 7.24 今日世界播报（保持期钩子）

每天一句动态播报，如"旧礼堂今天在下雨""傍晚的湖面有传闻"，构成日常回访理由，替代打卡签到。

### 7.25 成长 / 探索度（替代等级）

不做 Lv / XP，改以探索度与世界观呈现：校园探索度、已发现地点/历史/人物/传闻/记忆数量；世界观随探索越来越完整。

### 7.26 可变世界与周期洗牌（可玩性支柱）

地图固定是最大风险，用三层解法维持可玩性：

1. **周期洗牌（软肉鸽）**：每个学期/季节周期，传闻、异常、资源点位置、NPC 作息随机重排，玩家带已有进度进"新的一季"；每日再给一个"随机线索组合"当随机种子。轻量，不做死亡重开。
2. **你的地图因你而变**：记忆是钥匙 + 足迹 + 记忆节点，使同一地图每个玩家看到的内容不同，地图随玩家经历持续改写。
3. **UGC 可变地图**：玩家自建/自定义地图、NPC、内容，图本身不再固定（见 7.27）。

### 7.27 开发者模式 / 自定义模式

新增核心功能，把内容生产变成玩法的一部分，并直接补足"内容不够、地图固定"的缺口。其架构前提是第 4 节第 6 条：**一切内容数据驱动**——地图、地点、NPC、任务、资源、事件、养成配方、异常、传闻全部是配置/数据表，编辑器只是这些数据的可视化入口。

**开发者模式（课设组用）**

- 可视化编辑地图元素、人物、任务、养成内容、事件时序。
- 导出为世界数据。
- 同时作为录入校园内容与答辩演示的工具。

**自定义模式（玩家用）**

- 改"我的空间"外观与布局。
- 自定义 NPC（接入自己的 API）。
- 导入 / 切换主题地图包。
- 调规则：定位精度、单机/多人。

**范围与阶段**

- 第一版先做开发者可视化编辑器（客观需要录入内容）。
- 玩家自定义模式做轻量（外观 + 接 API + 切主题包）。
- 完整 UGC 与分享放后期。

## 8. 玩家第一周体验（"第一年春"类比）

- **Day 0（新手引导）**：进入校园，解锁"我的空间"（含种植台），发现第一个地点（旧礼堂），学会记录一条记忆节点。
- **Day 1–3（表层熟悉）**：采集、钓鱼/养鱼、拜访一两位 NPC，图鉴出现第一批条目，探索度稳步上升。
- **Day 4–7（首次触达深层）**：探索度 / 图鉴达阈值，或依一条传闻在特定时间地点蹲守，首次触发异常 / 过去地图碎片，打开"生活之下"的认知入口。
- 此后进入自由循环，玩家自选路线。

## 9. 范围与优先级

### P0（核心，一定做）

地理地图 + 六边形迷雾、探索/足迹、地点系统、时间/天气/世界状态、日记 + 记忆节点、世界图鉴、采集、种植、钓鱼/养鱼、加工（简化产线）、建设与自由建造、资源与货币（六类 + 三币）、数据驱动内容层。

### P1（第二层，非常值得做）

工具升级线、宠物/友善生灵、稀有变异收集、随机事件、NPC 与熟悉度（含 API 轨）、传闻、世界异常（特殊任务）、历史第二张地图、轻社交（可配置）、节日、可变世界与周期洗牌、开发者可视化编辑器。

### P2（有余力再做）

职业/生活方向、关系系统深化、今日世界播报、成长/探索度可视化、玩家自定义模式（完整）、遗迹/考古、世界异常深化、网页版。

### 明确不做（第一版）

战斗、大量敌对生物、复杂装备系统、重度等级/XP、完整经济模拟器、复杂工业自动化（产线只做简化版）。
